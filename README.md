# My Link - Agregador de Links Pessoais

Página web minimalista no estilo link-in-bio desenvolvida com HTML e CSS puros para reunir, organizar e facilitar o compartilhamento de redes sociais e contatos em um único endereço.

---

### Funcionalidades
- Exibição de perfil com foto e identificação
- Botões interativos para redirecionamento rápido de links
- Layout responsivo adaptado para dispositivos móveis e desktop

---

### Tecnologias Utilizadas
- **Estruturação:** HTML5
- **Estilização e Layout:** CSS3
